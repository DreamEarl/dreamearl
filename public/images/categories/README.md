# Category Images

This folder contains images for category/subcategory selectors displayed on the shop page.

## Required Images for Bags Category:

1. **phone-sling-bag.jpg** - Image of a phone sling bag (beaded/pearl style)
2. **hand-bag.jpg** - Image of a hand bag (beaded/pearl style)
3. **crossbody-bag.jpg** - Image of a crossbody bag (beaded/pearl style)

## Image Specifications:

- **Format:** JPG or PNG
- **Recommended size:** 400x400px minimum (square aspect ratio preferred)
- **File size:** Optimize for web (< 200KB recommended)
- **Style:** Product photos with clean background, preferably matching your brand aesthetic

## Adding New Categories:

To add images for other categories, update the `SUBCATEGORIES` configuration in `/lib/constants/shopConfig.ts` and add the corresponding images to this folder.
